# e-plantShopping

**e-plantShopping** is a dynamic React e-commerce application built for plant enthusiasts to explore, select, and purchase various household and garden plants seamlessly.

## Overview
This application provides an intuitive shopping experience featuring:
- **Landing Page:** A welcome screen with application overview and quick entry point.
- **Product Catalog:** A categorized selection of plants with detailed pricing, descriptions, and interactive "Add to Cart" capabilities.
- **Shopping Cart & State Management:** Powered by Redux Toolkit to handle live cart updates, item quantity adjustments, dynamic price calculations, and seamless navigation.

## Repository Details
- **Repository Name:** `e-plantShopping`
- **Framework:** React + Vite
- **State Management:** Redux Toolkit
- **Deployment:** GitHub Pages
